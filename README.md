# България, но в числа

> **„Истории за страната ни, които се крият в данните.“**

Модерно, минималистично и интерактивно едностранично дигитално издание за визуализация на официални статистически данни за България.

## 🇧🇬 Основни теми и модули

1. **Модул 01 — Заплати и покупателна способност (2015–2026 г.)**
   - Сравнение между нарастването на средната брутна заплата и инфлацията (ИПЦ).
   - Индексна база ($2015 = 100$), номинални стойности в евро (€) и лева (лв.).
   - Крива на реалната покупателна способност.

2. **Модул 02 — България по региони**
   - Интерактивна класация на всички 28 области в България.
   - Сравнение по средна заплата и демографска промяна (Преброяване 2011–2021 г.).
   - Търсене, сортиране и детайлен преглед на избрана област.

3. **Модул 03 — България в Европейския съюз**
   - Сравнение с 27-те страни членки на ЕС.
   - БВП на човек от населението по паритет на покупателната способност (ППС).
   - Действително индивидуално потребление (AIC).

4. **Любопитни факти & Методология**
   - Курирани статистически акценти с проверени първични източници.
   - Пряка прозрачност с връзки към каталозите на НСИ, Eurostat и БНБ.

## 🛠️ Технологичен стек

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Visualizations:** Recharts
- **Icons:** Lucide React
- **Data storage:** Локални структурирани JSON набори

## 🚀 Стартиране на проекта локално

1. Клонирайте хранилището:
```bash
git clone https://github.com/YOUR_USERNAME/bg-v-chisla.git
cd bg-v-chisla
```

2. Инсталирайте зависимостите:
```bash
npm install
```

3. Стартирайте dev сървъра:
```bash
npm run dev
```

Отворете [http://localhost:3000](http://localhost:3000) в браузъра си.
